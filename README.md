# Bid Arena

多人实时拍卖间（Bid Arena）——全栈线上实操评测项目。

## 项目简介

一个可供真人用户、测试脚本用户与竞拍 Agent 同时参与的多人实时拍卖间。

- **前端**：Vue 3 + TypeScript（Vite + Pinia）
- **后端**：Java 17 + Solon 3.x（HTTP API + WebSocket）
- **数据**：MySQL 8（唯一事实来源）
- **交付**：Docker Compose 一键启动
